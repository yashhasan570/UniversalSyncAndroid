Это продолжение клиента Universal Sync для Android, включающее значительные улучшения, к примеру:
* Folder, device and overall sync progress can easily be read off the UI.
* "Universal Sync Camera" - an optional feature (with optional permission to use the camera) where you can take pictures with your friend, partner, ... on two phones into one shared and private Universal Sync folder. No cloud involved. - FEATURE CURRENTLY IN BETA STAGE -
* "Sync every hour" to save even more battery
* Индивидуальные условия синхронизации могут быть применены отдельно для устройств и папок
* Интерфейс для недавних изменений, открытие файлов по нажатию.
* Changes to folder and device config can be made regardless if Universal Sync is running or not
* UI explains why Universal Sync is running or not.
* Проблема с расходом батареи решена.
* Discover other Universal Sync devices on the same network and easily add them.
* Supports two-way synchronization on external SD card since Android 11.

Universal Sync-Fork для Android - это обёртка для Universal Sync, предоставляющая интерфейс Android вместо встроенного в Universal Sync веб-интерфейса. Universal Sync заменяет проприетарные облачные сервисы чем-то открытым, достойным доверия и децентрализованным. Ваши данные - только ваши, и вы достойны решать, где они будут храниться, будут ли они доступны третьим сторонам и как они будут передаваться через Интернет.

Цели форка:
* Разрабатывать и проверять улучшения вместе с сообществом
* Выпускать новые версии приложения чаще, чтобы найти и исправить ошибки, связанные с изменениями в подмодуле Universal Sync
* Сделать улучшения конфигурируемыми в интерфейсе, пользователи должны иметь возможность включать и выключать их

Сравнение между основным приложением и этим форком на момент написания:
* Both contain the Universal Sync binary built from the official source at GitHub
* Функционал и надёжность Universal Sync зависит от версии бинарного подмодуля sycthing.
* Форк идёт в ногу с оригиналом, и иногда они подтягивают мои изменения.
* Стратегия и частота релиза отличается
* Форк касается только обёртки, содержащей Android UI .
